# Dataset

This project uses the Offensive Language Identification Dataset (OLID) for classifying social media text into offensive and non-offensive categories.

## Required Files

Download the dataset from the [OLID GitHub repository](https://github.com/idontflow/OLID).

- `olid-training-v1.0.tsv`
- `testset-levela.tsv`
- `labels-levela.csv`

Place these files in this `dataset` folder before running the training script.

## Dataset Labels

- `OFF` — Offensive
- `NOT` — Not Offensive

## Purpose

The dataset is used to train and evaluate a machine learning model for offensive language detection.

Please review the original dataset's terms and attribution requirements before using it.
